# Chrome 扩展更新日志

扩展单独发版，标签为 `ext-vX.Y.Z`，版本号取自 `apps/chrome-extension/package.json`。推送标签后，扩展工作流把对应段落写进 GitHub Release 的说明，所以**打标签前先在这里写好该版本的条目**。

## [未发布]

## [0.1.1] - 2026-10-30

仍然需要 Nexus Portal 服务端 0.3.0 或更高版本。

### 变更

- 新标签页的快捷方式扩展区与门户首页保持一致：鼠标移到首排时临时展开，移出后自动收起；点击面板下方的箭头按钮固定展开，再次点击收起。按钮移到面板底部居中，可点击范围更大，平时弱化显示。

### 更新方法

- 把新的 ZIP 解压到原来的文件夹，再到 `chrome://extensions` 点扩展卡片上的刷新按钮。连接和缓存都会保留。

## [0.1.0] - 2026-10-29

第一个版本：Chrome 开发者模式手动安装，需要 Nexus Portal 服务端 0.3.0 或更高版本。

### 新增

- 用扩展内置的页面替换 Chrome 新标签页，复用门户首页的组件：壁纸、时钟、搜索、快捷方式、分组与全部应用、服务状态、首页显示设置。
- 本地缓存优先：打开新标签页时直接显示上次同步的导航，不等网络；随后在后台检查更新。
  - 有变化时更新缓存和已打开的页面；没有变化时服务端只回一个很小的 304。
  - 30 秒内不重复检查；多个新标签页同时打开时只有一个去同步。
  - 断网或服务端故障时继续显示缓存，不会清空页面。
- 图标和壁纸缓存在 IndexedDB 中：最多 400 个图标、6 张壁纸、80 MB，最久未用的先清理。
- 连接与授权：
  - 只读设备令牌，经门户中登录的用户核对连接码并确认后才发放。
  - 扩展只申请 `storage` 权限，以及用户填写的那一个门户地址的访问权限。
- 扩展设置页：连接状态、最近同步时间、立即同步、清理缓存、更换服务器、断开连接（同时撤销令牌）。
- 授权被撤销、访问密码更改或缓存损坏时：清除本地导航数据，提示重新连接或重新下载。
