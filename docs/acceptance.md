# 验收清单（v0.1 第一阶段 + v0.2）

自动化部分：`npm test`（单元 / 组件 / 服务端，184 项）与 `npm run test:e2e`（Playwright：桌面 Chrome、本机 Microsoft Edge、WebKit 模拟 iPhone 13，共 70 项），以及镜像冒烟测试 `scripts/smoke-container.sh`。v0.2 发布前另做了一次真实的升级与回滚演练（0.1.0 镜像 → 0.2 → 恢复自动备份回到 0.1.0）。GitHub Actions 在每次推送时运行除 Edge 以外的全部项目。
下面是**必须在真机上确认**的项目——模拟器无法完全覆盖 iOS Safari 的键盘、地址栏与主屏幕行为。
