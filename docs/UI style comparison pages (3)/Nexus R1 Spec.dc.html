只动两种属性　透明度和 transform 用于所有动效，面板高度是唯一的例外，并且只用在搜索面板和手机底部面板上。
退出更快　退出时长约为进入的 0.7 倍，使用 exit 曲线。不用弹簧，也不做回弹。
同时最多两组　同一时刻运动的元素不超过两组，第二组延迟 40–60ms 开始。
减少动态效果　系统开启 prefers-reduced-motion 时，去掉所有位移、缩放和壁纸模糊，只保留 120ms 的淡入淡出，并关闭异常呼吸动画。
